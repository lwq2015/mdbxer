# MDBXer 功能点与知识点

> libmdbx 数据库只读查看工具（Rust + egui）。
> 本文档随开发持续维护：**功能新增/修改、知识点与踩坑解决后，同步更新对应章节**。
> 最后更新：2026-10-01

---

## 1. 项目概述

- **定位**：libmdbx 数据库的只读图形查看器，界面参考 MDB Ray。
- **约束**：纯只读，绝不写入数据库；中文 UI/注释；运行时加载 CJK 字体。
- **技术栈**：Rust 2024 edition（本机工具链 1.98.1）；`eframe`/`egui`/`egui_extras` 0.36.2；`libmdbx-rs`（git master，vorot93 版）；`rfd` 0.15（文件对话框）；`chrono`（仅 std/clock，时间戳格式化）；`serde`/`serde_json`（历史记录）。
- **构建**：`cargo build --release`（LTO thin，opt-level 3）；release 下 `windows_subsystem = "windows"` 不弹控制台。
- **默认窗口**：1280×760，最小 900×560，支持文件/目录拖入。

## 2. 分层架构与文件地图

单向依赖：`main → ui → db / fmt / history`。

```
src/
├── main.rs              入口；窗口选项；CJK 字体加载；命令行参数直开
├── history.rs           打开历史（JSON 持久化，最多 20 条）
├── db/                  数据库访问层（只依赖 libmdbx + std）
│   ├── mod.rs           OpenMode（自动/单文件/目录）与导出
│   ├── handle.rs        环境只读打开、subDB 枚举（DbHandle/TableInfo）
│   ├── page.rs          锚点分页、方向遍历、跳转、多值(DUP_SORT)读取
│   └── stats.rs         表统计 / 环境信息，格式化为键值行
├── fmt/                 格式解析层（纯函数：std + chrono）
│   ├── mod.rs           DecodeMode（17 种格式）、Endian（LE/BE）
│   ├── guess.rs         自动类型猜测
│   ├── value.rs         字节→显示文本（零扩展补齐、时间戳识别、截断）
│   └── hexdump.rs       十六进制转储（地址/HEX/ASCII 开关、行宽）
└── ui/                  界面层（只接触 db 层暴露的纯数据结构）
    ├── mod.rs           MdbxerApp 全局状态、分页/跳转/多值动作、wheel_cycle
    ├── topbar.rs        顶栏（连接 + 视图设置，单行紧凑）
    ├── sidebar.rs       左栏：表列表过滤/排序
    ├── dataview.rs      数据页签：工具条 + egui_extras 虚拟表格
    ├── detail.rs        右栏：Key/Value 卡片（格式/复制/文本/hex/多值翻页）
    └── statsview.rs     表统计、环境信息两个页签
```

**隔离原则**：fmt 是纯函数层，可单测；db 层把 libmdbx 的错误统一转 `String`、数据转成自有结构（`Row`/`Page`/`TableInfo`），UI 不直接出现 libmdbx 类型（除函数内部游标）。

## 3. 功能点清单

### 3.1 打开与连接（顶栏第一区）

- 路径输入框：回车或"打开"按钮打开；支持把文件/目录**拖入窗口**直接打开；支持**命令行传路径**（也可拖文件到 exe）。
- 三种打开模式：**自动 / 单文件 / 目录**。自动模式按路径是文件还是目录判断；对应 MDBX 的 `MDBX_NOSUBDIR`。
- 只读打开：`DatabaseOptions { max_tables: Some(4096), no_sub_dir, accede: true, mode: Mode::ReadOnly }`。
  - `NoWriteMap` 包装；`accede` 允许查看正被其他进程占用的库。
- "文件"/"目录"按钮调系统对话框（rfd），选择后自动设置对应模式并打开。
- **历史记录**：最多 20 条，同路径去重置顶；存 `%APPDATA%\mdbxer\history.json`；下拉内可点 ✕ 单条删除；写盘失败静默退化为内存记录。

### 3.2 左栏：表列表

- 通过遍历主表 key 逐个试探 `open_table` 枚举命名子表；**主表始终显示且固定首位**（显示"（主表）"）。
- 表名必须是合法 UTF-8 才能作为子表名；主表中试探失败的普通记录跳过。
- 主表 entries 包含所有命名表名字记录（引擎真实内容，浏览主表时可见）。
- 过滤框（大小写不敏感，匹配显示名）；排序：名称 ↑↓ / 条数 ↑↓（下拉支持滚轮）。
- 每行显示：表名、条目数、标志描述（多值/整数键/定长多值/整数值/反序键/反序值）。

### 3.3 数据页签

#### 分页

- 默认每页 200 条，可选 50/100/200/500/1000（下拉，支持滚轮，切换后回到首页）。
- **锚点分页**：`Anchor = (key, _)`，只按 Key 定位；锚点用 `set_lowerbound(key, None)`（Key 不存在则落在其后第一条）；翻页时 `skip_anchor` 跳过本页末/首 Key。
- **"多取一条探针"**：每次取 `limit+1` 条，多出的一条只用于判断 `has_more`，随后 `truncate(limit)`。无需 COUNT，翻页成本与表大小无关。
- 首页 `first()`、末页 `last()`、下一页 `next()`、上一页 `prev()`；降序读取后在内存 reverse，保证 rows 始终按显示方向排列。
- 工具条：`⏮ ◀ ▶ ⏭`（符号按钮 + hover 提示），边界自动禁用。

#### 排序（点击列头）

- **Key 列**：切换全局遍历方向（升/降），翻页保持；未排序时列头纯文本"Key"不带箭头。
- **# / 类型 / Value 列**：当前页内排序，点击循环 升序 → 降序 → 恢复默认。
- 点击整列区域（文字或空白处）均生效（label + 空白 rect 双 sense）。
- "↺"按钮一键恢复为表中读取出来的顺序（hover 提示原文）。
- 键盘 ↑↓ 按**显示顺序**移动选中行；输入框聚焦时不抢键。

#### 跳转定位

- 输入 `hex(...)` / `0x...`：按十六进制字节（忽略空格/下划线/冒号，长度须偶数）。
- INTEGER_KEY 表：接受十进制数字；内部先试 u64 LE 8 字节，失败再试 u32 LE 4 字节。
- 其余输入按 UTF-8 文本字节。
- 升序用 `set_lowerbound(key, None)`、降序用 `set_upperbound`；多值表定位到 Key 级别（落在其第一个值）；命中显示"已定位"，否则"未找到不小于该 key 的记录"；跳转后绝对序号变为未知（多值表显示"本页 N 个 Key"）。

#### 多值表（DUP_SORT）：按 Key 分组显示

- **表格中每个 Key 只占一行**（不是把所有 `(key,value)` 对摊平）：翻页用 `NEXT_NODUP`/`PREV_NODUP` 在 Key 间跳跃，一个 Key 即使有上万个值也不会霸占整页，方便纵览多个 Key。
- 分组行 Value 列显示该 Key **第一个值的预览 + `〔N 个值〕` 后缀**（N 由 `mdbx_cursor_count` 直接取得，不遍历）；降序时游标停在该 Key 最后一个值，统一用 `first_dup` 回首值，保证两个方向预览一致。
- 选中分组行后，右栏 Value 卡片显示"第 i/total 个值"，提供完整导航：
  - **逐值** `◀ ▶`（边界停止）；**翻页** `⏪ ⏩`（±100 个值）；**首值/末值** `⏮ ⏭`；
  - **序号跳转**："跳至"框输入 1 起的序号回车，跨值页自动加载（`dup_goto`）；
  - **值搜索**：输入文本（按 UTF-8）或 `hex(...)/0x...`（按字节），在该 Key 的值中做**字节子串**匹配；`↑` 向前、`↓`/回车向后，从当前值的相邻位置开始，主方向无命中自动回绕，状态栏显示定位/回绕/未找到；
  - 每 100 个值一页（`DUP_PAGE_SIZE`）懒加载（`dups_of`）。
- `dups_of`：先 `cursor.set(key)` 精确定位，FFI 取总数，再 `iter_dup_of` 只遍历本页窗口；Key 不存在返回 `(0, [])`。
- `dup_find`：一次 `iter_dup_of` 枚举同时算出主方向命中与回绕命中（向后主区取最大序号、回绕取全局最大；向前主区首个命中即返回、回绕取全局最小）。

### 3.4 格式解析（17 种显示格式）

`自动 / utf8 / utf16(LE) / utf16(BE) / int8 / int16 / int32 / int64 / uint8 / uint16 / uint32 / uint64 / float / double / hex / dec / binary`

- **自动猜测**：优先可打印 UTF-8（允许 \t \n \r）；再按长度 8/4/2 猜 u64/u32/u16（带 LE/BE 后缀）；否则按二进制 hex；空数据显示"∅ 空"。
- **字节序开关**：顶栏"字节序 LE/BE"（默认小端），影响多字节整数、浮点与自动猜测；下拉支持滚轮逐格切换、边界停止不循环。
- **长度规则**：
  - 短于类型宽度 → **零扩展补齐**（小端补尾部、大端补头部，数值等价），文本后标"（补零）"；
  - 正好 → 正常显示；超长 → 取前 N 字节；空数据 → "（空）"。
- `uint64` 特殊：落在 Unix 秒（1e9..1e10）或毫秒（1e12..1e13）区间时附本地日期时间。
- `hex`：空格分隔大写十六进制；`dec`：空格分隔十进制；`binary`：每字节 8 位二进制。
- 单元格按"单元格"字符数截断并加省略号（64/128/256/512/1024/4096，默认 256）。
- 三层格式选择：顶栏"排版"（表格 Key/Value 列）、右栏 Key/Value 各自独立下拉（详情与复制文本）。

### 3.5 右栏详情

- Key 卡片标题 `Key #序号`（跳转后序号未知则只显示 Key）；Value 卡片多值时带翻页。
- 每卡片：独立格式下拉（支持滚轮）、复制按钮（复制解码后文本）、字节数；自动模式下显示"猜测：类型，N 字节"。
- 文本区可折叠（>512 字符默认折叠）；十六进制区默认展开。
- hex dump：地址/HEX/ASCII 三段独立开关；行宽 4/8/16/32（默认 8），宽行中间加空隙，末行补空格保证 ASCII 列对齐；最多渲染 64KB，超出标注。
- 右栏可整体收起（顶栏"详情"），默认宽 360，可调 240–720。

### 3.6 统计页签

- **表统计**：条目数、B+树深度、分支/叶子/溢出页数、页大小、数据总大小、表标志、标志位原始值（0x）。
- **环境信息**：按"几何/映射/事务/读者/主表"分组——文件上下限/当前大小/增长步长/收缩阈值、映射大小、已用/空闲页数、最后事务 ID、读者槽位/当前读者数、主表统计。
- 切表或重开库时缓存失效，懒加载。

### 3.7 其他交互

- 所有工具栏 ComboBox 悬停可滚轮切换：鼠标一个刻度走一格，触控板累计 40 点走一格，到首尾停止不循环（`wheel_cycle`，用 temp data 跨帧累计）。
- 底部状态栏：普通表 `表名 — 第 X~Y 条 / 共 N 条`；多值表 `表名 — 第 X~Y 个 Key / 共 N 个值对`（N 为对数，非 Key 数）；单文件/目录模式、每页条数、最近状态消息。
- 工具栏单行紧凑布局，不折行（详见第 5 节约定）。

## 4. 知识点

### 4.1 MDBX / libmdbx-rs

- master 分支 API：`Database<NoWriteMap>`（不是旧版 `Environment`）；`txn.open_table(name)`（不是 `open_db`）；游标 `txn.cursor(&table)`。
- 只读事务：`db.begin_ro_txn()`；表统计 `txn.table_stat(&t)`、标志 `txn.table_flags(&t)`；环境级 `db.info()`/`db.stat()`/`db.freelist()`。
- 游标定位：`first/last/next/prev`、`set_lowerbound::<K,V>(key, dup_value)`（返回 Option）、`set_upperbound`（实为 MDBX_TO_KEY_LESSER_OR_EQUAL，最大 ≤ key）、`set(key)`（精确定位 Key）；多值专用 `next_nodup/prev_nodup`（跨 Key 跳）、`first_dup/last_dup`、`iter_dup_of(key)`。
- **取 Key 的值总数**：C API `mdbx_cursor_count(cursor, &count)` 不移动游标即可返回当前 Key 的重复值数量；libmdbx-rs 安全层未封装，但导出了原始句柄 `cursor.cursor().0`，在本 crate 里用 `unsafe extern "C"` 自行声明调用（符号由 mdbx-sys 静态库提供，最终链接自动解析；2024 edition 下 extern 块需写 `unsafe extern "C"`）。
- 命名表机制：子表名是主表里的一条普通记录；枚举 = 遍历主表 + 试探 open_table。
- `INTEGER_KEY` 的键是本机字节序（x86 即小端）的定长二进制整数，不是十进制文本。
- `mdbx_dump` 输出对照：`=` 开头是元数据头（VERSION/geometry 等），不是记录；`HEADER=END … DATA=END` 之间才是 KV。

### 4.2 egui / eframe

- 面板顺序：`Panel::top/bottom/left/right` 先于 `CentralPanel` 声明；左右面板从中央区挤占宽度。
- `egui_extras::TableBuilder`：`.resizable(true)` + `Column::initial/at_least/exact/remainder`，`.clip(true)` 防长文本撑爆列；`body.rows(h, count, …)` 虚拟化只渲染可见行。
- ComboBox：`.width()` 只约束**收起按钮**宽度，弹层按内容自适应；`.height()` 限制弹层最大高（长列表 430）；`from_id_salt` 支持用元组做 id 区分同类多个控件。
- `Response::on_hover_text` 会消费并返回 Response，链式调用后要接返回值再复用。
- `ui.horizontal()` 超出不换行不滚动（直接裁切）；需要换行才用 `horizontal_wrapped`。
- 滚轮事件读 `ctx.input(|i| i.raw.events)` 里的离散 `Event::MouseWheel { unit, delta }`，比连续滚动累计更可控；帧间状态用 `ctx.data_mut(|d| d.insert_temp(id, v))`。
- CJK：`FontData::from_owned(vec)` 插入 fonts 后，把字体名 push 进 Proportional/Monospace 两个族的 fallback 链；按候选路径顺序尝试（msyh.ttc 等）。
- release 隐藏控制台：`#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`。

### 4.3 Rust 技巧

- **edition ≠ 编译器版本**：edition（2015/2018/2021/2024）是一组破坏性语言变更的开关（2024 自 Rust 1.85 起成为 cargo new 默认），在 Cargo.toml 声明；编译器版本（如 1.98.1）独立持续发布，新库与非破坏性特性不受 edition 限制。升级 edition 只影响本 crate，依赖不用重编；本项目无 unsafe、无 gen 等冲突标识符，2021→2024 零代码改动。
- **匿名生命周期 `'_`**：如 `Cursor<'_, RO>`——位置必须有生命周期参数但无需具名时占位；只有需要表达跨参数/返回值的生命周期关系时才具名（如 `fn foo<'a>(x: &'a T) -> &'a T`）。
- 宏生成重复代码：`macro_rules! int`/`float` 统一各整数/浮点宽度的零扩展解码。
- 切片越界防护：不要写依赖急切求值的 `need()` helper；用 `if bytes.len() < n { … } else { … }` 先判长度再切片，`try_into()` 前用 match 保证长度。
- 锚点分页中"多取 1 条"是嵌入式 KV 通用手法，避免全量 COUNT。

## 5. 工程约定（UI/交互）

- 表格默认显示"表中读取出来的顺序"；未排序时 Key 列头无箭头。
- 四列列头均可点排序；Key 列管全局方向，其余列管页内排序（升→降→默认循环）。
- 工具栏坚持**单行紧凑**：不折行、不拆两行；宽度不够时按优先级处理——缩窄控件 → 按钮符号化（⏮◀▶⏭，含义放 hover）→ 删冗余信息（范围只留状态栏）→ hover 补充说明。
- 下拉收起宽度用 `.width()` 显式收紧（弹层不裁内容）：打开模式 70、历史 56、字节序 54、排版 92、单元格 60、每页条数 60、表排序 86；跳转输入框 88。
- 数值短于类型宽度：零扩展补齐并标"（补零）"，不显示"长度不符"。

## 6. 踩坑记录与解决

| 问题 | 原因 | 解决 |
|---|---|---|
| `egui_extras` 开 `table` feature 报错 | 0.36.2 表格已内置 | 删除 Cargo.toml 中该 feature |
| `Environment`/`open_db` 不存在 | libmdbx-rs master API 变更 | 改用 `Database`/`open_table` |
| 下拉滚轮跳项、首尾循环 | 连续滚动事件多次触发 | 离散 MouseWheel 按单位累计 + clamp 边界停止 |
| 数值解码越界 panic | helper `need()` 内表达式急切求值导致越界切片 | 改 if/else 先判长度再安全切片 |
| 主表不显示 | 旧逻辑仅在无命名表时显示 | 主表始终显示并固定首位 |
| binary 格式显示成 ASCII 转义 | 实现错误 | 改为每字节 8 位 `00101011` |
| 短数据显示"长度不符" | 早期直接判长度报错 | 零扩展补齐（LE 补尾/BE 补头）+ "（补零）"标注 |
| 默认窗口工具栏显示不全 | horizontal 单行内容超宽被裁 | 单行紧凑化：缩宽、符号按钮、去重复信息（不折行） |
| 多值表摊平显示，单 Key 值过多时几十页看不到别的 Key | 用 next/prev 遍历把每个 (key,value) 对当一行 | 改为按 Key 分组：next_nodup/prev_nodup 翻页 + mdbx_cursor_count 显示值数量，值浏览放右栏 |
